Coach feedback

A popular star count no longer lowers the score

What was happening

The training set averages about 52,500 stars. A count such as 43,000 sat below that center, so the star count pushed the score down.

What happens now

At 1,000 stars or more, a negative star-count contribution is removed. Counts above the training average still raise the score.

Stars per day, the busiest day, and burstiness are unchanged. A burst of stars can still lower a score.

Coach feedback

Run it three ways. Keep the notes out of the model.

  • Libraryscore_repository returns the score, the tier, and the signals.
  • Commanduv run trust-score prints the same result from the terminal.
  • Agent skillThe project skill tells an agent to score from metadata and not to clone the repo.
  • About rightThe score matches what you expected.
  • Too highThe number looks generous.
  • Too lowThe number looks harsh.

Notes from the page, the API, or the annotate option go to a local file. Training does not read that file.
